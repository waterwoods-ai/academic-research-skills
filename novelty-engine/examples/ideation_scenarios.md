# Ideation Scenario Checks

Synthetic scenarios for manual review or a fresh-session behavioral trial.
These are expected outcomes, not evidence that a live agent has passed them.
Judge decisions and provenance, not exact output wording. No network, model
execution or GPU job is needed for a static walkthrough.

| Scenario | Input | Expected outcome |
|---|---|---|
| No supported assumption | Papers provide no common untested dependency; a confirmed baseline limitation exists | Return zero supported assumptions, do not invent a dogma, continue through B |
| Adjacent transfer | Candidate combines neighboring techniques with complementary failures and a defined switching rule | Admit to mechanism/prior-art checks; do not reject for disciplinary proximity |
| Observation with rival explanations | Located development log shows cross-device degradation; both device shift and split leakage remain possible | Create C ledger; keep cause hypothetical; require a probe distinguishing shift from leakage |
| Missing observation artifact | User remembers a surprising score but cannot supply setup or logs | Produce a probe/data request; do not mark reproduced or shortlist a purported finding |
| Measurement-only lead | A supported measurement exposes an important security phenomenon but proposes no new algorithm | Hand off to S2 and the matching contribution route, without inventing a method or theorem |
| Uncertain search | No close prior work is retrieved because search access failed | Keep UNCERTAIN and out of the eligible shortlist; do not claim originality or fabricate a matching paper |
| Route duplicates | A and C produce the same mechanism with different names | Merge with both provenance records; do not reserve one seat per route |
| Proposal scores only | Three candidates have LLM novelty scores but no runs | Leave tests NOT RUN; require frozen development screening before method commitment |
| All tests fail | Every candidate misses its frozen criterion | Record UNMET and root-cause investigation; return evidence to generation without lowering the criterion |
| Borrowed component | A candidate cites a known component but proposes a concrete new coordination mechanism | Search the coordination delta; do not discard merely because an ingredient is known |

Record the actual execution mode when using these scenarios: static walkthrough
or live trial, model/runtime if applicable, supplied sources, observations and
unresolved issues. A static pass does not establish future agent behavior or
scientific effectiveness.
